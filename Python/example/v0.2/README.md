# Newcode 0.2 Examples

These examples introduce compound values, files, modules, tests, and the
development tools. Beginner lessons are in `For Beginners/`; one-error
programs are in `Errors/`.

```sh
python3 -m goodthink check "example/v0.2/For Beginners/01_calculator.think"
python3 -m goodthink run "example/v0.2/For Beginners/01_calculator.think"
python3 -m goodthink test "example/v0.2/For Beginners/13_tests.think"
```

Read `For Beginners/Grammar Explanation.md` for the step-by-step language
introduction and `Errors/Grammar Explanation.md` for diagnostic examples.

## 한국어

이 예제들은 복합 자료형·파일·모듈·테스트·개발 도구를 소개합니다. 초보자 수업은
`For Beginners/`, 오류별 프로그램은 `Errors/`에 있습니다.

위 명령처럼 `check`, `run`, `test` 명령으로 예제를 확인할 수 있습니다.
자세한 문법은 `For Beginners/Grammar Explanation.md`, 진단 예제 설명은
`Errors/Grammar Explanation.md`에서 확인합니다.
