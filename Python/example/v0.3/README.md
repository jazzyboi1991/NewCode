# Newcode 0.3 예제

- `14_string_tools.think`: 문자열 길이·검색·치환·분리·결합
- `15_nested_records.think`: 중첩 `recordthink`와 필드 접근
- `16_multiline.think`: 여러 줄 문자열과 확장 escape

저장소 루트에서 다음처럼 실행합니다.

```sh
python -m goodthink run "Python/example/v0.3/14_string_tools.think"
python -m goodthink check "Python/example/v0.3/15_nested_records.think"
```
