# Newcode 0.3 Examples

These examples demonstrate the expanded string features and nested records:

- `14_string_tools.think`: string length, search, replacement, splitting, and joining
- `15_nested_records.think`: nested `recordthink` values and field access
- `16_multiline.think`: multiline strings and extended escapes

From the repository root:

```sh
python3 -m goodthink run "Python/example/v0.3/14_string_tools.think"
python3 -m goodthink check "Python/example/v0.3/15_nested_records.think"
```

## 한국어

이 예제들은 문자열 기능 확장과 중첩 기록을 보여 줍니다.

- `14_string_tools.think`: 문자열 길이·검색·치환·분리·결합
- `15_nested_records.think`: 중첩 `recordthink` 값과 필드 접근
- `16_multiline.think`: 여러 줄 문자열과 확장 escape

저장소 루트에서 다음처럼 실행합니다.

