# Newcode 0.1 Examples

This directory is reserved for Newcode 0.1 compatibility examples. Programs in
this version should begin with `newcode 0.1`. The current beginner and error
examples are organized under `../v0.2/`.

## 한국어

이 디렉터리는 Newcode 0.1 호환성 예제를 위한 위치입니다. 이 버전의 프로그램은
첫 줄에 `newcode 0.1`을 적어야 합니다. 현재 초보자·오류 예제는 `../v0.2/`에
정리되어 있습니다.
