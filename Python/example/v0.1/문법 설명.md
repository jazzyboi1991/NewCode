# Newcode 문법 예제

이 디렉터리는 Newcode 문법을 작고 집중된 `.think` 파일들로 설명합니다. 하나의
큰 예제에 모든 문법을 넣지 않고, 각 파일이 하나의 주요 문법 특징을 보여주도록
나누었습니다.

`NewCode/` 디렉터리에서 다음처럼 실행합니다.

```sh
PYTHONPATH=Python python3 Python/goodthink.py check Python/example/v0.1/04_conditionals.think
PYTHONPATH=Python python3 Python/goodthink.py run Python/example/v0.1/04_conditionals.think
```

입력 예제는 표준입력이 필요하므로 다음처럼 실행할 수 있습니다.

```sh
printf '7\nAlpha\n' | PYTHONPATH=Python python3 Python/goodthink.py run Python/example/v0.1/09_input.think
```

## 00. 헤더와 주석

모든 프로그램은 언어 버전 헤더로 시작합니다.

```newcode
newcode 0.1
```

현재 구현은 버전 `0.1`을 받습니다. 헤더 뒤와 문장 사이에는 빈 줄을 둘 수
있습니다.

Newcode는 두 종류의 주석을 지원합니다.

```newcode
// 한 줄 주석
/* 블록 주석 */
```

주석은 parser가 무시합니다. 주석 밖의 소스 코드는 ASCII여야 합니다.

## 01. 선언과 대입

변수는 `thought`, 자료형, 이름, `be`, 표현식으로 선언합니다.

```newcode
thought numberthink count be 1
thought wordthink label be "Count"
thought goodthink approved be good
```

대입도 `thought`를 쓰지만 자료형을 다시 적지 않습니다.

```newcode
thought count be count plus 4
```

Newcode에는 암시적 자료형 변환이 없습니다. `numberthink` 변수에는
`numberthink` 표현식만, `wordthink` 변수에는 텍스트만, `goodthink` 변수에는
불리언 값만 넣을 수 있습니다.

## 02. 숫자와 산술

`numberthink`는 정수와 십진수를 지원합니다. 산술은 기호 대신 단어 연산자를
사용합니다.

| 연산자 | 의미 |
| --- | --- |
| `plus` | 더하기 |
| `minus` | 빼기 |
| `times` | 곱하기 |
| `divide` | 나누기 |

괄호로 계산 순서를 제어할 수 있습니다.

```newcode
thought numberthink grouped be (first plus second) times 2
```

숫자는 정확한 유리수 산술로 표현됩니다. 반올림은 고정 자릿수로 출력할 때만
일어납니다.

## 03. 문자열과 `join`

문자열은 `wordthink` 값입니다.

```newcode
thought wordthink first be "New"
thought wordthink second be "code"
```

`join` 연산자는 두 `wordthink` 표현식을 이어 붙입니다.

```newcode
thought wordthink label be first join second join " grammar"
```

식별자, 문자열 리터럴, 입력 텍스트, `join`으로 만들어진 값은
`Python/prohibited_words.json` 검열 lexicon으로 검사됩니다. 즉 금지 표현을
여러 문자열로 쪼갠 뒤 나중에 합쳐 우회할 수 없습니다.

## 04. 조건문

조건문은 `verify`, 선택적 `otherthink`, `endverify`로 작성합니다.

```newcode
verify approved
    speak "Condition accepted."
otherthink
    speak "Ungood."
endverify
```

조건은 반드시 `goodthink`여야 합니다. `more`, `less`, `same` 같은 비교
연산자는 `goodthink`를 만듭니다. 불리언 연산자는 다음과 같습니다.

| 연산자 | 의미 |
| --- | --- |
| `both` | 논리 and |
| `either` | 논리 or |
| `un` | 논리 not |

비교식을 부정할 때는 괄호를 쓰는 것이 안전합니다.

```newcode
verify un (count less 0)
```

괄호 없이 `un count less 0`처럼 쓰면 `un`이 숫자 `count`에 직접 적용되어
자료형 오류가 납니다.

## 05. 반복문

반복문은 `repeatwhile`과 `endrepeat`로 작성합니다.

```newcode
repeatwhile count less 6
    thought count be count plus 1
endrepeat
```

반복 조건은 반드시 `goodthink`여야 합니다.

반복문 안에서는 다음 제어문을 사용할 수 있습니다.

- `nextrepeat`는 다음 반복으로 넘어갑니다.
- `stoprepeat`는 가장 가까운 반복문을 종료합니다.

`nextrepeat`와 `stoprepeat`는 `repeatwhile` 블록 안에서만 유효합니다.

## 06. Routine

Routine은 top-level 선언입니다.

```newcode
routine numberthink addgood(numberthink first, numberthink second)
    reportvalue first plus second
endroutine
```

Routine 선언은 다음 요소로 구성됩니다.

- `routine`
- 반환 자료형
- routine 이름
- 0개 이상의 typed parameter
- 본문
- `endroutine`

값을 반환하는 routine은 `reportvalue`를 사용해야 합니다. routine 호출은
표현식이므로 선언, 대입, 출력, 다른 routine 호출 안에서 사용할 수 있습니다.

Routine은 중첩할 수 없고, 재귀 호출도 금지됩니다. 전역 변수를 직접 읽을 수
없으므로 필요한 값은 파라미터로 전달해야 합니다.

## 07. Silence Routine

`silencethink`는 반환값이 없는 routine을 표시합니다.

```newcode
routine silencethink announce(wordthink message)
    speak message
endroutine
```

`silencethink` 호출은 문장으로 사용할 수 있습니다.

```newcode
announce("Silence routine prints and returns no value.")
```

반환값이 없으므로 표현식 값이 필요한 자리에는 `silencethink` routine을 쓰지
않는 것이 좋습니다.

## 08. 출력과 소수 자릿수

`speak`는 한 줄을 출력하고, 쉼표로 구분한 여러 항목을 조합할 수 있습니다.

```newcode
speak "two digits: ", share to 2
```

Newcode는 공백을 자동으로 넣지 않습니다. 출력에 공백이 필요하면 문자열 안에
직접 넣어야 합니다.

`to`는 해당 숫자의 출력 소수 자릿수를 지정합니다. `speaknumber`는 더
엄격해서 정확히 하나의 `numberthink` 표현식만 받습니다.

```newcode
speaknumber half to 1
```

## 09. 입력

입력은 표현식으로 사용합니다.

```newcode
thought numberthink amount be listennumber
thought wordthink label be listenwords
```

`listennumber`는 한 줄을 읽어 정수나 십진수로 해석합니다. `minus 3` 같은
prefix 형태도 받습니다. `listenwords`는 ASCII 한 줄을 읽고 검열 lexicon으로
검사합니다.

`09_input.think`는 표준입력이 필요하므로 pipe로 값을 전달하거나 두 줄을 직접
입력해야 합니다.

## 연산자 우선순위

parser는 이항 연산자를 낮은 우선순위에서 높은 우선순위 순서로 처리합니다.

| 우선순위 | 연산자 |
| --- | --- |
| 1 | `either` |
| 2 | `both` |
| 3 | `more`, `less`, `same` |
| 4 | `join` |
| 5 | `plus`, `minus` |
| 6 | `times`, `divide` |

단항 `un`과 단항 `minus`는 primary expression으로 묶입니다. 단항 연산자와
비교식 또는 산술식을 함께 쓸 때는 괄호로 의도를 명확히 하는 것이 좋습니다.

## 현재 구현의 경계

현재 구현에는 배열, map, 객체, 파일, 모듈, 네트워크 접근, 암시적 자료형
변환, 프로그램 내부에서 공식 lexicon을 수정하는 기능이 없습니다. 이 작은
범위는 syntax, type checking, vocabulary control을 직접 살펴보기 위한
의도적인 제약입니다.
